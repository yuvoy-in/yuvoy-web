# Plans

Tracked implementation plans for non-trivial work. Each captures context, root-cause analysis, the workstream breakdown, and decisions — so the reasoning survives across sessions.

## Convention

- One Markdown file per initiative, descriptive kebab-case name.
- Keep it updated as workstreams ship: mark each `SHIPPED (staging / prod)` inline.
- Committed and shareable. The project-wide source of truth is `../../../YUVOY_TECHNICAL_MASTER_PLAN.md`; these are scoped implementation plans under it.
